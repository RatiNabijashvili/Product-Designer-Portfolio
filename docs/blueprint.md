# **App Name**: Minimalist Portfolio

## Core Features:

- Navigation Bar: Implement a navigation bar with a logo placeholder and a 'Contact Me' button.
- Hero Section: Design and implement the hero section with 'Scroll Me' text and a video display.
- Descriptive Text Blocks: Create text blocks with specified fonts and styles for 'A, Quietly, Confident' and 'Product Designer'.

## Style Guidelines:

- Background color: Very light gray (#FCFAFA) for a clean, unobtrusive backdrop.
- Primary color: Dark gray (#030C0C) for text elements to ensure readability and contrast against the background.
- Accent color: Black (#181818) for the 'Contact Me' button, providing a strong visual call to action.
- Headline font: 'Anton' (sans-serif) for the 'Product Designer' text, providing a bold and impactful statement.
- Body text font: 'Satoshi' (sans-serif) for all other text elements, offering a modern and legible appearance. Note: currently only Google Fonts are supported.
- Use a flexbox layout to align and space elements in the navigation bar and hero section.
- Maintain consistent padding and spacing (32px body padding, 112px block spacing, 16px element spacing) throughout the layout for visual balance.
- Use a simple arrow icon next to the 'Scroll Me' text, in dark gray (#030C0C).
